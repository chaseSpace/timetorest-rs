## 鼠标指针随屏幕色温与亮度同步调整

本版本使用 **Rust + Win32** 原生界面，面向 Windows 11 x64；Windows 10 兼容性尚未完整验证。macOS 正在开发中，暂不支持 Linux。

- 常用系统鼠标指针跟随屏幕色温、亮度和 180 ms 过渡，包括箭头、链接手形、文字选择和调整大小。
- 保留当前指针主题的大小、点击热点、透明区域和传统反色像素；关闭屏幕调节、选择“正常”或正常退出后恢复。
- 用户或其他程序中途更换指针时，停止覆盖受影响的指针；关闭再开启屏幕调节后重新读取当前主题。
- 指针同步失败时显示状态提示，屏幕调节继续工作；补齐中英文说明。

忙碌、后台工作等动画指针，以及应用自定义指针不参与调整。强制结束进程不执行恢复，可在 Windows 鼠标指针设置中重新应用主题。

通过 44 项 Rust 测试（含 5 项指针测试）、rustfmt、Clippy、Release 构建及发布脚本测试；1 项会调整桌面颜色的测试默认跳过。指针测试仅操作内存中的副本，不替换桌面指针。实际滑杆联动、多显示器、高 DPI、主题切换和退出恢复仍待人工验收；本次未重测常驻内存，旧版资源占用数据不代表本版实测。

下载 `leafshield-native-0.7.1.exe` 后直接运行，无需安装、WebView2 或 Node.js。升级前请从托盘退出旧版；配置继续沿用原目录。程序未签名，请使用同一发行中的 `SHA256SUMS.txt` 核对下载文件。
