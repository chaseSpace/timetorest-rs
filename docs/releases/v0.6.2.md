## 一叶 · LeafShield 0.6.2

- 修复锁屏时移动鼠标导致输入框出现后立即消失、反复闪动的问题。
- 使用各屏幕共享的输入屏幕状态控制解锁区域；窗口焦点交接和输入法短暂失焦不再隐藏输入框。
- 仍然默认隐藏解锁区域；移动鼠标或按键后显示并聚焦，切换屏幕时隐藏另一屏。
- 保留中英文界面、双语解锁文案、MIT 许可和 CareUEyes 鸣谢。

Windows 下载：`leafshield-0.6.2.exe`、`LeafShield_0.6.2_x64-setup.exe`，附 `LICENSE` 和 `SHA256SUMS.txt`。

macOS 通用包：`LeafShield_0.6.2_universal.dmg`，同时支持 Apple Silicon 和 Intel。Mac 构建完成后追加到本发行，附 `SHA256SUMS-macos.txt`。使用 ad-hoc 签名，未提供 Apple Developer ID 签名或公证。

界面和双屏交互由用户手动验收。

## LeafShield 0.6.2

- Fixed the unlock area appearing and immediately disappearing or flashing when the mouse moves during a break.
- Unlock visibility now follows a shared active-input-screen state. Window focus handoffs and temporary IME focus changes no longer hide the input.
- Unlock areas still start hidden, reveal and focus after mouse movement or a key, and hide on the previous screen when input switches screens.
- Includes Chinese / English UI and unlock phrases, the MIT license, and CareUEyes acknowledgments.

Windows downloads: `leafshield-0.6.2.exe`, `LeafShield_0.6.2_x64-setup.exe`, `LICENSE`, and `SHA256SUMS.txt`.

macOS Universal: `LeafShield_0.6.2_universal.dmg` for Apple Silicon and Intel. The Mac workflow adds it to this release with `SHA256SUMS-macos.txt` when ready. Ad-hoc signed without Developer ID signing or notarization.

Interface and real multi-monitor acceptance remain manual.
