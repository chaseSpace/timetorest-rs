## 一叶 · LeafShield 0.5.4

首个 GitHub 发行版，提供 Windows x64 便携版和当前用户安装包。

- 休息计时：默认 45/2，快捷组合 25/2、45/2、60/3、90/5，支持暂停和提前提醒。
- 多屏图片休息页、固定五条正念解锁文案、可选紧急通道及本机统计。
- 解锁区域默认隐藏，鼠标移动或按键唤出；本版修正双屏初始化消息触发显示的问题，并协调原生窗口、WebView 和输入框焦点。
- 提示文案不可复制；输入错误显示红色下划线，支持中文输入法。
- 悬浮计时四边吸附隐藏、EXE / 桌面快捷方式白名单、便携版默认开机启动。
- Windows 系统 RGB 色温 / 亮度调节，平滑过渡，不使用颜色遮罩窗口。
- 中英文 README 包含使用说明、技术栈和实现原理。

### 下载

- `leafshield-0.5.4.exe`：便携版。
- `LeafShield_0.5.4_x64-setup.exe`：安装包。
- `SHA256SUMS.txt`：这两个资产的 SHA256 校验值。

需要 WebView2 Runtime，发行文件未做代码签名。首次运行默认启用当前用户开机启动，可在选项关闭。正常运行无需 Node.js，也不会启动 HTTP 服务。

### 验证范围

发布流程从此标签源码构建 Windows 资产。本机发布编译及部分原生检查已完成；最新双屏交互和中文输入仍需用户手动验收。macOS / Linux 有源码适配和 CI 配置，本次不提供对应安装包，也不宣称完成真机验收。普通桌面程序无法阻止 Ctrl+Alt+Del、安全桌面或强制结束进程。

## LeafShield 0.5.4

The first GitHub release, providing Windows x64 portable and per-user installer packages.

- Break timer with a 45/2 default, presets 25/2, 45/2, 60/3, 90/5, pause, and advance reminders.
- Photo-based multi-monitor break screens, five fixed mindfulness phrases, an optional emergency exit, and local statistics.
- Unlock areas stay hidden until pointer movement or a key. This version filters dual-monitor initialization movement messages and coordinates native window, WebView, and input focus.
- Displayed phrases cannot be copied; incorrect input gets a red underline, with IME composition support.
- Edge-docking floating timer, EXE / desktop shortcut whitelist, and startup enabled by default in portable mode.
- Smooth Windows system RGB temperature / brightness adjustment without color overlay windows.
- Chinese and English READMEs describing usage, the technology stack, and implementation.

### Downloads

- `leafshield-0.5.4.exe`: portable executable.
- `LeafShield_0.5.4_x64-setup.exe`: installer.
- `SHA256SUMS.txt`: SHA256 checksums for those two assets.

WebView2 Runtime is required. Executables are not code-signed. Start at login is enabled by default and can be disabled in Options. Production execution requires neither Node.js nor an HTTP server. The application interface and unlock phrases are currently in Chinese.

### Verification scope

The release workflow builds Windows assets from this tag. Local release compilation and selected native checks have completed; latest dual-monitor and IME interactions still require manual acceptance. macOS / Linux source adaptations and CI configuration exist, but this release does not provide their packages or claim real-device acceptance. A desktop app cannot block Ctrl+Alt+Del, secure desktops, or forced termination.
