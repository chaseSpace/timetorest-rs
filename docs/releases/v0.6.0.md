- 多屏休息页、四边吸附计时、前台白名单、默认开机启动、离线背景及 Windows RGB 屏幕调节。
- 中英文 README 包含使用方法、技术栈、构建说明和四张界面截图；本地 `zzz/` 工作记录已忽略。

## LeafShield 0.6.0

Windows x64 portable executable and per-user installer.

- Chinese / English selection under Options → Language. Changes apply immediately and persist.
- Localized settings, break screens, floating timer, tray, notifications, error messages, and app-picker labels.
- Five unlock presets in each language. Switching languages keeps the selected preset; IME composition avoids premature errors, and English unlock text requires an exact match.
- Fixed clicks in other apps unexpectedly expanding the docked timer and resetting its hide delay.
- Multi-monitor breaks, edge-docking timer, foreground whitelist, default start at login, offline backgrounds, and Windows RGB screen adjustment.
- Chinese and English READMEs with usage, technology stack, build instructions, and four screenshots; local `zzz/` notes are ignored.

### Downloads

- `leafshield-0.6.0.exe`: portable executable.
- `LeafShield_0.6.0_x64-setup.exe`: installer.
- `SHA256SUMS.txt`: SHA256 checksums for those two assets.

WebView2 Runtime is required. Executables are not code-signed. Start at login is enabled by default and can be disabled in Options. Production use requires neither Node.js nor an HTTP server.

### Verification scope

37 Rust tests passed, including language changes preserving presets and preferences, legacy configuration migration, and exact English unlocking. TypeScript, rustfmt, Clippy, and translation-format checks passed. Real multi-monitor, English-interface, IME, and docking interactions still require manual acceptance. macOS / Linux source adaptations and CI configuration are provided without packages or real-device acceptance in this release.
