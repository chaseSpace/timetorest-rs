## LeafShield 0.6.1

- Added the standard MIT license and bilingual licensing notes, credited to Leigg (磊哥哥). Bundled photographs retain their own licenses.
- Acknowledged **CareUEyes**, which inspired the interface design and some features, in both READMEs and the About page.
- Includes 0.6.0's Chinese / English interface, bilingual unlock phrases, and floating-timer click fix.

Download the portable `leafshield-0.6.1.exe` or the installer `LeafShield_0.6.1_x64-setup.exe`. Assets also include `LICENSE` and `SHA256SUMS.txt`; checksums cover both executables and the license.

WebView2 Runtime is required. Start at login is enabled by default and can be disabled in Options. Real multi-monitor, IME, and interface acceptance remains manual.
