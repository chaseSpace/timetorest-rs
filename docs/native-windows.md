# Windows 原生开发版

开发分支：`dev.win`。当前版本：`0.7.0-dev.4`，当前仅支持 Windows 原生界面，暂不支持 macOS。

## 构建与运行

```powershell
npm run build:native
```

运行 `artifacts/native-dev/leafshield-native-0.7.0-dev.4.exe`，无需 Node.js、WebView2 或安装步骤。
构建目录同时包含 MIT LICENSE 和 SHA256SUMS.txt。该命令只生成测试程序，不启动 HTTP 服务、不安装、不发布 Release。

测试前从托盘退出旧版，再启动原生版，避免同时计时及调节屏幕颜色。
原生版沿用 `%APPDATA%/com.leafshield.desktop/settings.json`，首次启动会保留
`settings.pre-native-dev1.json` 备份。文件损坏时另存备份再恢复默认值；保存失败回滚操作。
开发版启动时不改写现有开机启动项；在“选项”切换开机启动时才将其应用到当前 EXE。

## 本次范围

`dev.2` 修复更新文字时的白色矩形、色温滑杆反向，以及点击滑杆只分段移动的问题。
启用系统视觉样式，设置页采用浅色侧栏、圆角面板与按钮、Segoe UI 字体及 Fluent 图标；仍使用 Win32 / GDI。

`dev.3` 将 LeafShield 移到系统标题栏左上角，删除侧栏的重复名称。修复滑块坐标缓存导致轨道长度为零的问题；轨道绘制和点击定位直接使用实际通道范围。系统托盘的同步 / 异步回调均使用与悬浮窗一致的右键菜单，关闭设置页后仍可用。

`dev.4` 在“开启紧急解锁”下方常驻显示中英文说明，交代入口、20 秒内 50 次按键、2 秒间隔 / 超时重置、长按限制和解锁日志。修复滑杆拖动后旧圆形游标超出原生失效区域造成的残影，鼠标操作隐藏焦点提示，键盘操作保留圆形焦点提示。

- 原生设置窗口：显示器、定时器、解锁、白名单、选项、关于。支持中英文及原有四组时间预设。
- 原生托盘、悬浮计时、拖动和四边吸附隐藏、鼠标穿透。
- 所有显示器同步休息，默认隐藏解锁区域和鼠标；活动屏幕显示原生输入框。
- 五条预设解锁文案、禁止粘贴、输入不匹配时红色下划线、中文输入法组合输入处理、紧急解锁。
- 默认背景及有大小限制的自定义图片、EXE / LNK 白名单选择、旧配置兼容。
- 沿用原 RGB 矩阵、色温算法及 180 ms 过渡；算法移入共享 Rust 核心供两个界面复用。

## 自动测试

当前开发版的编译、workspace Clippy 和共享核心 / 原生程序的 39 项 Rust 测试通过；1 项会调整桌面颜色的原生测试保持跳过。
白块回归用内存 DC 直接验证“状态正在更新时仍能正确处理控件绘制”，不会打开窗口或操作用户界面。
便携 EXE 与 LICENSE 的 SHA-256、x64 GUI PE 和依赖树检查通过，记录见 `artifacts/native-dev/verification.json`。

```powershell
npm run build:native
npm run test:native-ui
```

Windows 界面自动测试会创建临时配置，启动真实原生窗口，检查标题栏名称、两条滑杆的轨道像素、25% / 50% / 75% 点击位置、拖动、两处右键菜单一致、托盘同步 / 异步回调、暂停 / 继续、六个设置页面及关闭设置后的托盘操作。报告及截图保留在 `artifacts/native-dev/ui-test-<时间>/`。

`dev.4` 共通过 18 项界面检查，新增中英文紧急说明完整显示 / 不重叠检查，以及连续移动后的实际屏幕像素比对。该比对先复现 dev.3 的 260 个残留像素；dev.4 两条滑杆均为 0。

测试配置通过 `--ui-test-profile` 传入，使用独立互斥量。该模式不启动系统颜色调节或全局键盘钩子，开机启动开关也仅写入临时偏好，测试结束后退出该进程。它不操作正在运行的普通版本。

## 后续验收

自动测试覆盖本次界面与托盘修复；以下系统交互仍需另行验证：

1. 显示调节是否保持平滑，退出后颜色是否恢复。
2. 双屏进入休息时均隐藏输入框，移动鼠标或键入后仅当前屏显示，输入法首字、切屏和焦点是否正常。
3. 错字红线、禁止粘贴、完整解锁、到点自动结束与紧急通道。
4. 悬浮窗左右上下吸附、隐藏、展开；点击其他应用不会触发展开。
5. 中英文布局、高 DPI、白名单选择与延后、设置及开机启动偏好持久化。
6. 分别记录托盘常驻、悬浮窗、设置界面、双屏休息的内存及 CPU；确认没有 WebView2 子进程。

内存数值以该 EXE 的实际测量为准。目前没有把此前讨论的预算当成实测结果。
程序启动并保持在要测量的界面后，可执行以下只读采样；脚本不会启动或结束程序：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/profile-native-windows.ps1 -Mode floating
```

`-Mode` 支持 `tray`、`floating`、`settings`、`rest`，用于标记人工设置的状态，脚本不会切换界面。
报告写入 `artifacts/native-dev/performance-<Mode>.json`。

Windows 安全桌面、Ctrl+Alt+Delete、任务管理器等系统通道仍不属于应用可完全禁止的范围。
