## 0.1.0 性能实测

Windows 本机、12 个逻辑处理器，普通工作态预热 10 秒后采样约 10 秒。CPU 按逻辑处理器数归一化；0.000% 为本次短样本四舍五入结果，不代表零 CPU 消耗。

| 指标 | 本次结果 |
| --- | --- |
| Rust 宿主工作集 | 28.30 MiB，约 29.67 MB |
| Rust 宿主 Private Bytes | 6.05 MiB |
| Rust 宿主 CPU | 0.000%（短样本） |
| WebView 子进程工作集合计 | 410.60 MiB |
| WebView 子进程 Private Bytes 合计 | 259.76 MiB |
| 整个进程族 CPU | 0.000%（短样本） |
| 进程族数量 | 8 |

工作态进度环已改为按秒更新，避免每一秒都连续插值渲染。优化前一次冷启动短样本的进程族 CPU 为 1.666%，记录在 `artifacts/performance-before-render-tuning.json`；预热条件不同，该对比只能作为排查线索。

Rust 宿主处于需求给出的 15–30 MB 区间；整组应用存在显著的 WebView 额外开销，不能宣称整应用仅占 15–30 MB 或比约 200 MB 的 Electron 应用更省内存。各进程工作集包含共享页，简单求和也不等于唯一物理内存。可见锁屏状态 CPU <2% 以及长期运行资源稳定性仍需实测。

## 验收边界

Windows 本机验证与 macOS/Linux 源码支持分别记录；跨平台源码可编译性不等同于这些平台的真机验收。系统安全桌面及受保护快捷键不属于普通桌面应用可以全面屏蔽的范围。性能目标须实测，不以框架选择代替结果。
