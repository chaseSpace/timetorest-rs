这是一份为你量身定制的跨平台（Rust 驱动）屏幕护眼软件——“一叶障目 (LeafShield / EyeGuard)” 的完整产品需求文档（PRD）。
软件的核心亮点在于结合了 Rust 的轻量高效 与 “强制输入正念文案”的心理学解锁机制，彻底根治用户“习惯性跳过休息”的痛点。

📄 产品需求文档 (PRD)

1. 产品定位与核心价值

• 产品名称（暂定）： 默醒 (MindLock) / 或者是你喜欢的名字。
• 开发语言： Rust (后端/系统级控制)
• 跨平台支持： Windows, macOS, Linux (Ubuntu/Debian)。
• 核心痛点： 传统护眼软件一键即可跳过，用户毫无抵抗力。本软件通过“强制输入正念文案（>
10字）”增加多巴胺阻断屏障，迫使大脑在打字时进行理性思考，真正达到强制休息的目的。

2. 核心功能需求（Functional Requirements）

2.1 倒计时与工作状态（Work Timer Module）

• 时间设定： 用户可自由设定工作时长（默认 45 分钟）和休息时长（默认 5 分钟）。
• 常驻 UI：
• 支持桌面角落半透明悬浮倒计时（可设置鼠标穿透，不干扰工作）。
• 系统托盘（Tray）图标显示进度条或剩余分钟数。
• 前置提醒（预警）： 锁定前 60 秒、30 秒弹出轻量气泡通知，防止用户在写代码或开会时被突然锁屏。

2.2 心理学强制锁屏模块（正念解锁）🔒

• 全屏独占锁定：
• 倒计时归零时，软件自动拉起一个全屏独占置顶窗口（Fullscreen Topmost Window）。
• 屏蔽常见系统级快捷键（Windows 键、Alt+Tab、macOS Mission Control 等），确保无法被轻易切回后台。
• 多屏幕支持： 识别多显示器，锁屏时所有屏幕同步变黑或显示休息壁纸，防止用户把视线移到副屏继续工作。
• 文案解锁机制（核心亮点）：
• 锁屏界面不提供“跳过”按钮。
• 提供一个文本输入框，用户必须手动完整输入系统预设或自定义的、大于 10 个字的惩罚/正念文案（例如：“我知道休息不足可能会伤害眼睛和大脑，继续解锁”）。
• 限制增强： 禁止在输入框内使用 Ctrl+V (粘贴) 键，必须纯手打。
• 字数不足或错别字时，解锁按钮保持灰色禁用状态。

2.3 UI/UX 美学设计（Aesthetics & Theme）

• 极简毛玻璃（Acrylic / Vibrant）：
• 锁屏界面采用毛玻璃大幕，若隐若现透出底层工作桌面，降低压迫感的同时保证无法看清工作内容。
• 动态视觉抚慰：
• 锁屏时大字显示倒计时。
• 背景伴随缓慢的呼吸灯动效，或者随机展示大自然（绿植、远山、星空）的高清壁纸。
• 提示语动态轮换：“请起立喝水”、“转动眼球，眺望窗外 6 米远”。

2.4 配置管理（Settings Module）

• 文案自定义： 内置5条解锁文案可供选择（必须检测 >10 字）。
• 紧急呼救（白名单）： 允许设置极少数白名单程序（如 Teams/Zoom 会议中不锁屏），或提供一个极其苛刻的“突发紧急解锁”通道（如需要连续狂敲键盘
50 下，并记录在“偷懒日志”中）。

3. 技术选型建议（Rust 跨平台生态）

为了同时兼顾 UI 美观（现代感） 和 Rust 底层系统控制，推荐以下两种技术组合方案：

方案  Tauri + Vue3/React (HTML/CSS)    tauri 内置 Rust 后端 + enigo / window-shadows 界面最美观。

🛠️ 关键 Rust 依赖库（Crates）推荐：

• tauri: 跨平台应用骨架，处理托盘和窗口通信。
• rdev / enigo: 用于全局监听或拦截键盘事件（防止 Alt+Tab 逃逸）。
• sysinfo: 检测系统当前是否有全屏游戏或视频会议在运行，决定是否延缓锁屏。

4. 非功能性需求与性能指标

• 内存占用： 纯 Rust 核心常驻内存保持在 15MB - 30MB 之间（远低于 Electron 护眼软件的 200MB+）。
• CPU 消耗： 倒计时期间 CPU 使用率 < 0.5%，锁屏渲染期间 < 2%。
• 权限安全性： 锁屏需要调用系统底层窗口置顶权限，在 macOS 上需要在“安全性与隐私 -> 辅助功能”中引导用户授权。
• 提供exe直接运行和可安装版本构建选项（默认前者）
